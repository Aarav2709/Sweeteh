Config

Every option, with its default. Settings covers all of them too, and is searchable.

Options live in ~/.config/sweeteh/config.json, which reloads as you save it. Write only what you change, everything else keeps its default.

{
  "theme": { "roundness": 0.8 },
  "launcher": { "maxResults": 10 }
}

From a terminal, sweeteh ipc config set theme.roundness 0.8 does the same, and sweeteh ipc config reset theme.roundness puts a default back.
