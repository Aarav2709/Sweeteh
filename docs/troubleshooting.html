Troubleshooting

What to check when something does not look or work right.

The shell is gone

The shell restarts itself after a crash. If it stays gone, start it from a terminal and read what it prints:

sweeteh run

The log of the last run, and any crash the system recorded:

qs -c sweeteh log
coredumpctl list quickshell

A feature says something is missing

When a feature needs a package that is not installed, the island names it. Type >install missing packages in the launcher to install what is missing, or run sweeteh update.

Colors did not change

  • Type >recolor from wallpaper in the launcher.
  • A fixed theme overrides the wallpaper. Pick Wallpaper in Settings, Appearance to follow it again.
  • Apps pick up new colors when they start. Kitty and GTK apps that are already open may need a restart.

Keybinds do nothing

Keybinds are handed to Hyprland when the shell starts. If you installed with --keep-configs, check that your own config does not bind the same keys, and that it starts the shell.

More than one monitor

There is nothing to set up. The bar, wallpaper, desktop widgets, lockscreen and screen corners appear on every monitor, and the island and its panels open on the one in focus. Arrange and scale monitors in your hyprland.lua, the shell follows as they come and go.

Fingerprint unlock

The lockscreen takes a fingerprint beside the password once fprintd has a finger enrolled. Check the state with:

sweeteh fingerprint

Reporting a bug

Open an issue on GitHub with what you did, what happened, and the output of qs -c sweeteh log.
