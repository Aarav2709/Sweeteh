Launcher

Press Super and type. Apps, files, sums and conversions answer straight away, and one first character turns the search into something else.

Searching

With nothing but a name typed, the launcher looks through:

  • Apps. The ones you open at this hour and lately rise to the top. CtrlEnter or a right click shows an app's own actions, like a private window.
  • Shell actions. Toggle Wi-Fi, lock, pick a wallpaper and the rest of the palette.
  • Files in your home folder. CtrlEnter shows the file in its folder.
  • The web, as the last row.

Sums like 12 * 4.5 are answered as you type, and conversions like 10 km to mi or 20 usd in eur a moment later. Enter copies the answer.

On an empty search, a link, a sum or a path you just copied is offered first.

Command palette

> alone lists every shell action, with what you use most first. Tab completes a word and Ctrl with a number picks a row. It also answers these:

Your own commands

Add rows to launcher.commands in ~/.config/sweeteh/config.json. They show in the launcher and in the palette.

{
  "launcher": {
    "commands": [
      { "title": "Sync notes", "command": "rclone sync ~/Notes remote:notes", "icon": "sync", "terminal": true },
      { "title": "Work VPN", "command": "nmcli connection up work", "keywords": "network office" }
    ]
  }
}
FieldMeaning
titleThe row's name. Needed.
commandA shell line. Needed.
iconA Material Symbols name. A terminal icon when left out.
keywordsExtra words the row can be found by.
terminaltrue runs the command in your terminal so you can see it.
