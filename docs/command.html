The sweeteh command

Start, stop and update the shell from a terminal, and call anything inside it from a script or a keybind.

Commands

CommandWhat it does
sweeteh runStart the shell. If it crashes it starts again by itself, and gives up after five crashes in a minute.
sweeteh stopStop it.
sweeteh restartStop and start again.
sweeteh checkPrint the newest release if there is one.
sweeteh updateMove to the newest release, with any packages it needs, and restart.
sweeteh fingerprintShow whether fingerprint unlock is set up for the lockscreen.
sweeteh ipc …Call a function inside the running shell.

Updates

Sweeteh follows tagged releases. It checks for a new one a minute after login and every six hours after, says so in the island, and Settings, About has an Update button. sweeteh update does the same from a terminal.

When a release needs new packages the update installs them too, asking for your password in the island. If that is cancelled, the island says what is missing and >install missing packages in the launcher tries again.

Calling the shell

sweeteh ipc takes a target, a function and its arguments. Bind these to keys in Hyprland or use them in scripts.

sweeteh ipc launcher toggle
sweeteh ipc wallpapers random
sweeteh ipc mode set island
sweeteh ipc config set theme.preset nord
sweeteh ipc island message "Build finished"
