Getting started

Install Sweeteh on Arch or an Arch based distro with one line. You do not need Hyprland first.

Install

curl -fsSL https://raw.githubusercontent.com/Aarav2709/Sweeteh/main/install.sh | bash

The installer asks before it installs packages, then:

  • installs Hyprland, Quickshell and everything else Sweeteh needs with pacman
  • turns on NetworkManager, Bluetooth and power profiles
  • puts the newest release in ~/.local/share/sweeteh and a sweeteh command in ~/.local/bin
  • sets up Hyprland, kitty, fish and the starship prompt with the Sweeteh configs
  • starts Hyprland when you log into tty1 if you have no login screen
  • adds a few wallpapers to ~/Pictures/Wallpapers if it is empty
Your old configs are kept Every file the installer replaces is moved to ~/.local/state/sweeteh/backups/ first, and uninstalling puts them back.

Options

Pass options through curl by adding -s -- after bash.

curl -fsSL https://raw.githubusercontent.com/Aarav2709/Sweeteh/main/install.sh | bash -s -- --keep-configs
OptionWhat it does
--keep-configsKeep your own Hyprland, kitty, fish and starship configs. See below for the one line your Hyprland config then needs.
--no-depsSkip installing packages.
--dry-runShow what would change without changing anything.
--uninstallRemove Sweeteh and put your previous configs back.
--purgeWith --uninstall, also delete Sweeteh settings, backups and cache.
-yDo not ask before installing packages.

Keeping your own Hyprland config

With --keep-configs nothing starts the shell for you. Add this to your hyprland.lua:

hl.on("hyprland.start", function() hl.exec_cmd("sweeteh run") end)

From a clone

Run the installer inside a clone and the shell runs straight from that folder, so your edits show up live.

git clone https://github.com/Aarav2709/Sweeteh
cd Sweeteh
./install.sh

First steps

A short tour opens on first start. After it, these get you around:

PressTo
SuperOpen the launcher
SuperAOpen the island, with quick settings, the calendar and notifications
Super,Open settings
Super.Show every keybind
SuperShiftWPick a wallpaper

Everything works from the keyboard. Tab moves between controls, Enter or Space presses them and Esc closes whatever is open. Type >welcome in the launcher to see the tour again.

Uninstall

curl -fsSL https://raw.githubusercontent.com/Aarav2709/Sweeteh/main/install.sh | bash -s -- --uninstall

Add --purge to also delete your Sweeteh settings, backups and cache.
