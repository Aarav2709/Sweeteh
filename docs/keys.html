Keys

The default keybinds. Super period shows this list on your desktop.

Change any of them in Settings, Keybinds, where you press the new keys to set them. They are kept under keybinds in the config and handed to Hyprland for you.

Apps

KeysDoes
SuperOpen the launcher
SuperTOpen the terminal
SuperEOpen the file manager
SuperWOpen the browser

Windows

KeysDoes
SuperQClose the window
SuperVFloat or tile the window
SuperFMake the window fullscreen
SuperDMaximize the window
SuperJFlip the split direction
Super←Focus the window on the left
Super→Focus the window on the right
Super↑Focus the window above
Super↓Focus the window below
SuperSShow the scratchpad
SuperShiftSSend the window to the scratchpad

Shell

KeysDoes
SuperAOpen the island
SuperTabOpen the workspace overview
SuperShiftVOpen clipboard history
CtrlShiftEscOpen the system monitor
Super.Show keybinds
Super,Open settings
SuperShiftWPick a wallpaper
SuperShiftMSwitch the layout
SuperShiftEEdit desktop widgets

Session

KeysDoes
SuperEscOpen the power menu
SuperLLock the screen
SuperMLog out of Hyprland

Capture

KeysDoes
Screenshot keyCapture a region
PrintCapture a region
SuperScreenshot keyCapture the whole screen
SuperShiftRStart or stop a screen recording
SuperShiftGSearch part of the screen with Google Lens

Media

KeysDoes
SuperShiftNName the song that is playing

Zoom

KeysDoes
SuperCtrlScroll upZoom in around the cursor
SuperCtrlScroll downZoom out
Super=Zoom in around the cursor
Super-Zoom out
SuperCtrl0Stop zooming

In the shell

These work in every panel and are not rebindable.

KeysDoes
TabMove between controls
Enter or SpacePress the control in focus
EscClose whatever is open
Ctrl1 to 9Run that row in the launcher
CtrlEnterThe second action of a launcher row
